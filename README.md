# Sample Python Code for Linear Regression

import numpy as np
from sklearn.linear_model import LinearRegression
import matplotlib.pyplot as plt

# Sample data
X = np.array([[1], [2], [3], [4], [5]])
y = np.array([3, 4, 2, 5, 6])

# Model
model = LinearRegression()
model.fit(X, y)

# Prediction
predictions = model.predict(X)

# Visualization
plt.scatter(X, y, color='blue')
plt.plot(X, predictions, color='red')
plt.title('Linear Regression Example')
plt.xlabel('Input Feature')
plt.ylabel('Target Variable')
plt.show()


This simple linear regression code demonstrates the foundation of machine learning, which is often taught in introductory AI courses. Understanding such fundamental concepts allows developers to implement more sophisticated AI solutions.
